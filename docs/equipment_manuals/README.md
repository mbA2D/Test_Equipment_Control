## Documentation status

The commercial equipment families now have the available datasheets and user/programming manuals collected in their corresponding folders. Remaining documentation gaps are:

- HP6632B: no separate datasheet; the programming guide and service material are present.
- IT8500: no separate datasheet; user and programming guides are present.
- KORAD KWR102/103: no separate datasheet; the user manuals include technical specifications.
- KORAD KA-series: no dedicated programming manual; the KA3005DS user manual is present.
- Custom A2D equipment: project-specific documentation is still needed for the A2D Power Board, A2D E-load, A2D DAQ, A2D Sense Board, isolated ADC, relay board, and Arduino I/O module.

The repository folder containing this index no longer stores the PDF copies; it is retained as the documentation pointer for the instrument drivers.
